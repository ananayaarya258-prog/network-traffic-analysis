# network-traffic-analysis

> Real-world PCAP investigations focused on malware analysis, network forensics, IOC extraction, incident response, and threat hunting.

---

## Project Overview

This repository contains hands-on traffic analysis investigations performed on real-world packet capture (PCAP) files.

Each case study documents a structured investigation workflow used to identify malicious activity, analyze network behavior, extract indicators of compromise (IOCs), and understand attacker communication patterns.

This project is designed to simulate Security Operations Center (SOC) and Blue Team analyst workflows.

---

## Core Objectives

- Analyze malicious network traffic
- Detect suspicious communication patterns
- Investigate malware infections
- Extract and validate IOCs
- Perform network-based threat hunting
- Strengthen incident investigation methodology
